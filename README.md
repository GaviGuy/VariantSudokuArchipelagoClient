# Variant Sudoku Archipelago
To set up:
1. Install the APWorld found in [this repository](https://github.com/GaviGuy/Archipelago/releases)
2. Download or generate a YAML and modify it to your liking
3. Generate and host a lobby as normal
4. Enter the server address, port, slot name, and password (if applicable) in the [web app](https://gaviguy.github.io/VariantSudokuArchipelagoClient/)
